# Smart Home Lighting Automation System

## CodeAlpha Robotics & Automation Internship

### Project Description

This project demonstrates a smart home lighting automation system using a PIR motion sensor, Arduino Uno, relay module, and LED.

## Components

- Arduino Uno
- PIR Motion Sensor
- Relay Module
- LED Bulb
- Power Supply

## Working

1. Motion is detected.
2. Arduino receives the signal.
3. Relay turns the light ON.
4. After no motion is detected for a preset time, the light turns OFF.

## Applications

- Smart Homes
- Offices
- Schools
- Warehouses
